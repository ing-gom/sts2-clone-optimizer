# StS2 Clone Optimizer

**파엘의 종양(Pael's Growth)** 휴식 **복제(Clone)** 이벤트를 대용량 덱에서도 멈추지 않게 해주는 **슬레이 더 스파이어 2** 모드입니다.

[English README](README.md)

## 문제

파엘의 종양의 휴식 옵션은 **덱에 있는 복제(Clone) 인챈트 카드를 전부** 복제하며, 그 수는 **휴식할 때마다 2배**로 늘어납니다. 바닐라는 이를 느린 방식으로 처리합니다 — 카드를 한 장씩 복제하면서 각각 날아드는 연출을 재생하고, 마지막에 **복제된 모든 카드**를 한꺼번에 미리보기(카드 1장당 노드 1개)로 띄웁니다. 복제 인챈트 카드가 많아지면 이 옵션을 누를 때 **한 프레임에 수 초간 멈춥니다**.

## 이 모드가 하는 일

복제 규모가 클 때, **같은 카드들을 그대로 복제**(게임 결과 동일)하되:

- 추가를 **배치 처리**하고 카드별 날아드는 애니메이션을 생략합니다.
- 작업을 **여러 프레임에 나눠** 게임이 멈추지 않고 반응을 유지합니다.
- 화면 **상단에 퍼센트 진행 바**를 표시해 진행 상황이 보입니다.
- 복제 연출은 카드 **일부 샘플**에만 재생해, 복제 수만큼 노드를 만들지 않습니다.

규모가 작은 복제는 **전혀 건드리지 않으며** 원래 연출을 그대로 유지합니다.

## 게임플레이가 바뀌나요?

아니요. 같은 카드들이 덱에 복제되며, 복제의 **렌더링과 타이밍만** 최적화됩니다. 카드 효과·RNG·결과는 변하지 않습니다. `affects_gameplay` 는 `false` 입니다.

## 설치

1. 최신 릴리스를 받습니다.
2. `Sts2CloneOptimizer` 폴더를 Slay the Spire 2 의 `mods/` 디렉터리에 넣습니다.
3. 게임 내에서 모드를 활성화합니다.

## 호환성

- 솔로 플레이 권장(대부분의 클라이언트 모드와 동일).
- 별도 설정 없이, 대용량 복제 이벤트에서만 자동으로 동작합니다.
